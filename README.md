# Previsão do Tempo

Uma aplicação elegante e moderna para consulta de previsão do tempo em tempo real para qualquer cidade do mundo.

## 🌟 Funcionalidades

- Informações meteorológicas em tempo real
- Exibição da temperatura em Celsius
- Descrição das condições climáticas
- Porcentagem de umidade
- Velocidade do vento
- Temperatura de sensação térmica
- Visualização de ícones do clima
- Design responsivo
- Interface com tema escuro moderno
- Suporte a pesquisa por tecla Enter
- Animações suaves
- Tratamento de erros

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- API OpenWeatherMap
- Google Fonts (Open Sans)
- Font Awesome (ícones)
- Glassmorphism (efeito de vidro)

## 🚀 Demonstração ao Vivo

Confira a aplicação funcionando [aqui](https://trindadelucas0.github.io/Previsao/previsao.html)

## 💻 Como Usar

1. Digite o nome de uma cidade no campo de busca
2. Clique no botão de busca ou pressione Enter
3. Visualize as informações meteorológicas incluindo:
   - Nome da cidade
   - Temperatura atual
   - Condição climática
   - Umidade
   - Velocidade do vento
   - Sensação térmica
   - Ícone do clima

## 🎨 Design

A aplicação apresenta uma interface moderna com:
- Fundo escuro semi-transparente com efeito de vidro
- Layout responsivo que se adapta a diferentes tamanhos de tela
- Efeitos de hover em todos os elementos interativos
- Tipografia limpa usando a fonte Open Sans
- Ícones do Font Awesome para melhor visualização
- Animações suaves nas transições
- Imagem de fundo dinâmica

## 📱 Responsividade

- Layout adaptativo para dispositivos móveis
- Ajuste automático de tamanhos de fonte
- Reorganização de elementos em telas menores
- Grid responsivo para detalhes do clima

## ⚙️ Funcionalidades Técnicas

- Tratamento de erros para falhas na API
- Validação de entrada do usuário
- Suporte a pesquisa por tecla Enter
- Carregamento inicial automático
- Animações de transição suaves
- Conversão de unidades (m/s para km/h)
- Ícones de alta resolução do clima
